# FB Growth Web

Interface web (Vite + React + Tailwind) reproduisant le funnel visuel de
Blow Up, branchée sur le backend fb-growth-bot (FastAPI/Render).

## Installation (Termux)
pkg install nodejs -y
npm install

## Lancer en local
npm run dev

## Build de production
npm run build
# résultat dans dist/ -> déployable sur Render Static Site, Vercel, Netlify
